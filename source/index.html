CardPilot 是一款本地化的信用卡管理工具。它不需要账号、不连接银行，也不会把数据上传到服务器。

✓本地存储
01

录入卡片

只记录管理所需信息。不要填写完整卡号、有效期、CVV、密码或短信验证码。

02

查看提醒

系统按账单日和还款日生成每月日历，并突出未来 7 天内的事项。

03

定期备份

使用“导出备份”保存 JSON 文件。换电脑时可从该文件恢复数据。

04

安全上传代码

GitHub 仓库只上传程序和匿名示例数据。真实备份文件已由忽略规则排除。

本地数据管理

重置会删除当前浏览器中的全部卡片，并恢复匿名示例数据。
