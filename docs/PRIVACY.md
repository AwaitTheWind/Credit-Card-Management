# 隐私与数据安全

CardPilot 是离线优先工具，不连接银行，也没有远程数据库。卡片数据保存在浏览器的 `localStorage` 中；除非用户主动导出或复制，否则应用不会发送这些数据。

## 不应记录的信息

- 完整信用卡号
- CVV/CVC 安全码
- 有效期与安全码的组合
- 银行登录密码、支付密码
- 短信验证码、动态口令
- 身份证完整号码

建议只用卡片昵称、银行、卡组织、额度、账单日、还款日、年费和权益进行管理。

## 备份

JSON 备份包含用户录入的全部卡片资料，应视为私密文件。建议放在加密磁盘或受保护的密码管理工具中。项目中的 `data/private/` 和 `outputs/private/` 已被 Git 忽略。

## GitHub

上传前应检查 Git 状态，确认没有真实 JSON/CSV 备份、截图中的个人资料或其他敏感文件。公开仓库中的 `source/app.js` 只包含匿名示例数据。
